## 1. Beyond Learning Academy

**Rol en el portafolio:** caso visual principal; muestra la construcción de un sitio web completo.

### Relato del caso — borrador para el portafolio

#### Construir una experiencia digital para una academia

Desarrollé de forma integral el sitio web y el portal digital de Beyond Learning Academy, llevando su experiencia visual hasta una interfaz funcional, responsiva y orientada a presentar su oferta de aprendizaje.

Implementé las interfaces con React y Tailwind CSS, y organicé componentes reutilizables basados en shadcn/ui. Conecté el frontend con servicios y API REST usando Axios, y revisé la calidad visual, la navegación y la adaptación a diferentes pantallas.

También desarrollé un CMS personalizado en Payload, incluyendo esquemas de datos y operaciones CRUD dinámicas, para administrar el contenido del sitio.

- Revisé visualmente las páginas y corregí problemas de navegación e interfaz.

## 2. Kuadra — evolución de un producto SaaS

**Rol en el portafolio:** caso principal de producto; muestra una trayectoria frontend sostenida desde 2024 a través de versiones y módulos de una plataforma SaaS en evolución.

### Relato del caso — borrador para el portafolio

#### Construir una experiencia coherente a través de todo el producto

Desde 2024 he trabajado en la evolución frontend de Kuadra, una plataforma para administrar las operaciones de un negocio. El producto ha pasado por varias versiones y reúne módulos para ventas, inventario, gastos, clientes, facturación electrónica, cierres de caja, reportes y otras tareas.

Los diseños de interfaz y experiencia llegaban desde Figma, preparados por un diseñador UI/UX. Mi responsabilidad era convertirlos en páginas funcionales y mantener una experiencia consistente a medida que se sumaban módulos y flujos. Para hacerlo, implementé el sistema de diseño en código y construí componentes reutilizables con shadcn/ui y Tailwind CSS.

Mi trabajo también incluía revisar el comportamiento de las interfaces con pruebas unitarias y de extremo a extremo. En ocasiones hice integraciones puntuales con APIs; mi aporte principal se mantuvo en frontend y QA.

Para mostrar ese alcance, el caso recorrerá tres ejemplos de la versión desplegada en cuya implementación colaboré: la gestión de gastos, el flujo de venta en el POS y el cierre de caja. Son tareas distintas, pero comparten patrones de navegación, filtros, acciones, tablas, estados y controles de interfaz.

#### Mi aporte

- Implementé en frontend diseños de Figma en múltiples módulos y versiones del producto.
- Desarrollé el sistema de diseño en código y componentes reutilizables con shadcn/ui y Tailwind CSS.
- Revisé calidad y comportamiento con pruebas unitarias, pruebas de extremo a extremo y validación funcional.
- Realicé integraciones puntuales con APIs cuando el flujo lo requería.

#### Resultado que podemos afirmar

Mi contribución ayudó a llevar los diseños a una interfaz funcional y a sostener patrones visuales reutilizables entre módulos. El caso documenta ese trabajo con ejemplos concretos, sin atribuir métricas de negocio que todavía no se han confirmado.
